# Anti-Noise Reference

- Collapse repeated stale warnings when there is no new evidence.
- Escalate only when frequency, urgency, or blast radius increased.
- Keep single-session signals out of top insights unless they create immediate risk.
- When the same dormant project is flagged 3 times, recommend archive, pause, or a revisit date.
- Do not create work just because a file exists. Tie every recommendation to user impact, future agent accuracy, or execution efficiency.
